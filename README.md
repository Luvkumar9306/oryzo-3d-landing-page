## ✨ Key Features

* **Real-time 3D Canvas:** Interactive WebGL background with reactive mouse tracking and particle simulation.
* **Modern Editorial Aesthetics:** High-contrast typography, minimalist layout, and fluid smooth-scroll interactions.
* **Component-Driven Architecture:** Modular React architecture built with Vite and Tailwind CSS.
* **Production Optimized:** Custom build configurations supporting relative paths and standalone preview via `start_landing_page.bat`.

---

## 🚀 Running Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Or double-click `start_landing_page.bat` to launch immediately in your default browser.
